# Lesson 1: First Words

**Level:** first words and short identification sentences  
**Contexts:** home, classroom, and nearby objects  
**Review:** `en/vocabulary/objects.md`, `en/locations/home.md`

## Goals

- Name familiar people and objects.
- Use the template `This is [thing].`
- Answer a simple yes/no question: `Is this [thing]?`

## Templates

### This is [thing].

- Examples: This is a book. This is a chair.
- Substitutions: book, chair, house, door
- Teaching note: Point to the object while saying the sentence.

### Is this [thing]?

- Examples: Is this a book? Is this a chair?
- Answers: Yes, it is. / No, it is not.
- Teaching note: Use real objects when possible; pictures are a good fallback.

### Teaching progression

1. Show all columns and have the learner match, listen, and repeat.
2. Hide English and ask the learner to identify the object from the target
   phrase.
3. Hide pronunciation and ask the learner to read the target script aloud.
4. Show only the target script and ask the learner to answer or produce a new
   sentence using a vocabulary substitution.

### Translation review

- Confirm that every target phrase is natural for the selected language,
  register, and region.
- Record gender, number, word order, politeness, and omitted words where they
  affect reuse.
- Add a dialect or cultural note when a phrase changes across communities.
- Keep the English column as a meaning reference, not as a word-for-word rule.
