# Hello

This is a simple dictionary that I will use to learn languages easily.

Learning a language `Arabic (in this case)` is so easy even a baby could do it. We will simply start with a phrase for example -

`This is...[x]`

In the above example, we can simple replace the `[x]` with anything -

- This is... `[a book]`
- This is... `[a car]`
- This is... `[a chicken]`
- This is... `[David]`
- This is... `[Sarah]`
- This is... `[a house]`
- This is... `[an Airport]`
